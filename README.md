# CodeAlpha E-Commerce Sales Analysis

## Project Overview
This project analyzes e-commerce sales data using Python to identify sales trends, product performance, and useful business insights.

## Internship
CodeAlpha – Data Analytics Internship

## Tasks Completed

### Task 2: Exploratory Data Analysis (EDA)
- Explored the dataset structure and data types.
- Checked for missing values.
- Calculated total revenue, quantity sold, and average order value.
- Analyzed sales by product, category, city, payment method, and month.
- Identified patterns and trends in sales data.

### Task 3: Data Visualization
Created charts to understand sales performance:
- Sales by Category
- Monthly Sales Trend
- Sales by City

## Tools Used
- Python

- Matplotlib
